# WMF compatibility tests

The `.wmf` files here are generated by `python scripts/generate-wmf-fixtures.py`.
Each has a same-named `.png` and `.json` generated by Windows GDI on the
`windows-2025` GitHub runner. The JSON records the WMF and PNG hashes, raster
settings, renderer source hash and oracle version. Changed inputs or settings get new
references; current cases are skipped.

The [Update Windows reference images](../../../.github/workflows/update-goldens.yml)
workflow runs on WMF/renderer changes to `master` and can be dispatched manually.
It commits only PNG/JSON outputs. Pull that bot commit before developing against
the new images. If branch protection prevents the bot pushing, grant GitHub
Actions write permission and allow its push, or use a dedicated reference-image
branch and merge the generated commit manually.

`test_layout.py` checks that these input fixtures still match the generator and
parses them. No pixel renderer is implemented yet, so committed PNGs are
reference data for the next rendering slice rather than asserted output.
