# EMF compatibility tests

The `.emf` files here are generated by `python scripts/generate-emf-fixtures.py`.
Each drawing is laid out on a 128-unit grid and recorded at several picture-frame
scales, so native playback fits it to the canvas at 1:1, up, down and by a
non-integer factor. Page-mapping cases are played at 1:1.

References are 128×128 PNGs in `128x128/`, rendered on the Windows oracle by
`PlayEnhMetaFile` onto the whole canvas, which is how `render()` and the Pillow
plugin fit the frame too. They are created by the same
[reference workflow](../../../.github/workflows/update-goldens.yml) as the WMF
references: commit new EMFs without PNGs and the job renders and commits them.
`test_emf_layout.py` checks that the generator reproduces every committed EMF
and that every reference matches exactly.
