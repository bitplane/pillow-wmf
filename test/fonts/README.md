# Controlled layout font

`layout.ttf` is generated by `scripts/test_font.py`. Its original geometric
outlines are dedicated to the public domain under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

Regenerate with `.venv/bin/python scripts/test_font.py`. FontTools is needed
only for generation and validation, not Windows reference rendering.

The font has a space and two deliberately asymmetric glyphs, A and B. B has a
negative left bearing and a descender. The em is 1000 units, Windows ascent and
descent are 900 and 300, and typographic ascent and descent are 800 and 200.
Those differing metrics distinguish cell-height and character-height requests.
There are no hinting instructions, kerning or shaping tables. This isolates
layout experiments; it is not representative coverage of real font hinting.
